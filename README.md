# waseshibu-pages (PUBLIC)

GitHub Pages公開専用リポジトリです。

`waseshibu-source` のGitHub Actionsが、ビルド済みWebアプリと
暗号化済みコンテンツだけをこのrepositoryの `main` へpushします。

初回だけ GitHub の

**Settings → Pages → Build and deployment → Source: Deploy from a branch**
- Branch: `main`
- Folder: `/ (root)`

を設定してください。

このrepoには元PDF、平文問題、模範解答、Root Keyを置きません。
